# Daily maintenance: formatting and management comparison - v0.0.2.84

## Evidence and scope

Observed contract failures had existing explicit values but unnecessarily entered
a second model pass: selected instruments included a native expiry suffix;
identical wake arrays appeared at both batch and sole-decision level; management
outputs omitted duplicate selection action/reason lines while their wire action,
wire reason and audit final choice were present. A corrected entry expressed
latency in that candidate's adjacent EXECUTION_UNCERTAINTY clause, which was not
included in geometry validation. Repair passes sometimes removed otherwise valid
evidence while fixing these formatting defects.

The worker now accepts the optional native expiry suffix in the two existing
selection readers; canonical root/scope checks remain. Identical wake copies
collapse only with unique ownership. Missing management action/reason mirrors
reuse explicit values only when wire action and final choice agree. Explicit
contradictions, missing judgment, invalid probability/verdict, foreign instruments,
off-tick prices and ambiguous ownership still fail. No action, probability, stop,
target or risk value is inferred. The selected candidate's optional execution
uncertainty contributes to its own geometry check, never another candidate's.

Management reasoning repeatedly treated an unreceipted proposed exit as inferior
and defended negative unchanged-bracket value by intact thesis alone. A short
clarification separates prospective action comparison from claiming execution:
compare exit at current native price after costs; receipt is required before
asserting completion. A superior managed continuation needs current evidence and
available actions, not unspecified future rescue. Ordinary noise/red marks are
still not automatic exits, and no fixed threshold or strategy gate is introduced.

## Proof and protected behavior

Focused regressions cover suffix/scope boundaries, identical versus conflicting
duplicates, missing versus contradictory mirrors, unchanged math/probability
validation, candidate-local uncertainty and original noise-tolerance doctrine.
Witnessed response replay is offline, with mocked invocation and no native calls.
Full-suite, publication, checkpoint, installed parity and runtime proof are
recorded separately in the private maintenance checkpoint.

No native AddOn, replication, protection, Flatten All, account setting, model,
cadence, learner or market-admission change. Source tests are not proof of trading
profitability. Closed-market admission remains enforced; natural new-release
cycle proof may await reopening. Rollback uses a scoped source revert and the
supported profile updater, preserving learning/configuration and native state.
