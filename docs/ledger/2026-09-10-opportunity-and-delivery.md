# Opportunity and delivery correction - v0.0.2.79

Surviving paths must be assessed with current supported geometry, not merely an
old remote stop against a consumed objective. A previously preferred pullback
does not need to earn the same confirmation again at a worse price. Waiting
still needs an explicit advantage; entry is never compulsory. Future extension
objectives require present evidence and uncertainty, not a previously printed
level or a fabricated destination.

Entry ranges retain strict latest-price revalidation and fill-relative native
bracket translation. Cognition explains actual validity boundaries instead of
arbitrary quote-centered bands. One already-completed prior call's observed
duration is supplied from its named attempt artifact; absent or malformed timing
is omitted. It is neither a latency forecast nor a required range width.

Market-map compaction preserves actual coverage when a requested 15/60-minute
window has fewer consecutive candles. Complete-window counts remain redundant.
No new indicator, score, threshold, action gate or budget increase is introduced.

The companion native indicator correction supplies omitted OHLCV and explicit
prior-completed-bar fields from the lightweight multi-instrument publisher. It
does not change feed priority or infer closed candles from the live partial bar.

Regression checks cover prior-call provenance, malformed/missing timing,
short-window compaction, existing context limits, stop survival, anticipatory
entries, native delivery revalidation and the full profile contract suite.
Native publication has an executable secondary-series JSON/locale fixture.
Private execution evidence and installation receipts remain outside this public
repository. Source tests are not evidence of profitability or live activation.

Protected: formulas, model, cadence, output schema, probability semantics,
management, learner rules, execution, protection, replication and compliance.
