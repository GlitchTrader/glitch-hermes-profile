# Maintain Glitch Runtime

Use this truth order: current NinjaTrader/Glitch native facts; immutable Glitch
packets, receipts, execution events, and journals; operator-confirmed facts;
Hermes-derived state and memory; inference.

Rebuild only Hermes-owned derived state. Reuse the same IDs for interrupted
delivery, clear a lock only after proving its owner is dead, and append every
correction. Never edit Glitch-owned trade truth, reset an account, erase a loss,
fabricate a fill, disable protection, loosen limits, or mark recovery complete
without current evidence.

If safety is unresolved, pause new AI entries only for the affected capability,
preserve native protection, keep unaffected operation running, and report the
exact evidence gap. Source defects become bounded Codex build requests with
reproduction, expected invariant, affected artifact, and acceptance proof.
Hermes never schedules or operates Codex.
